## 문구 — 세 단계 "왜 하는지"를 공식 사유로 교체

내가 쓰던 ①단 이득(`1-1, 1-2처럼 잘게 나뉜 문항도 경계가 확실해져요`)은 **폐기**.

| 단계 | 근거 원문 |
|---|---|
| ① 빈 활동지·문항 확정 | 문항 지시문을 미리 확정해 두면, 학생 제출물의 낙서·메모로 훼손된 지시문을 AI가 오독하는 것을 막는다 |
| ② 채점기준 연결 | 각 문항에 요구되는 채점기준만 적용해 평가한다 |
| ③ 모범답안·채점 가이드 | 선생님이 생각하는 "상" 수준을 AI가 파악해 추론이 불가능한 답안도 채점 / 채점 가이드로 채점 고려 사항을 반영 |

- ①은 두 안 중 **1안(낙서·메모 오독)** 채택 — 2안(*"답안에 더 집중"*)은 무엇이 좋아지는지가 흐리다.
  바꾸려면 `ADV_WHY[1]`·`ADV_GAIN[1]`·`ADV_LOAD.ws.why` 세 줄
- 업계어는 풀었다 — `훼손된 지시문 오독` → `낙서나 메모를 문제로 잘못 읽음`,
  `"상" 기준 수준` → `잘한 답안의 수준`, `추론 불가능한 답안` → `미루어 짐작하기 어려운 답안`
- **③단은 두 줄로 나눴다** — 모범답안과 채점 가이드는 서로 다른 이득이라 이어 붙이면 뒤엣것이 묻힌다.
  채점 가이드 쪽은 `적어 주세요`(부탁) → `적어 두면 … 선생님이 생각하시는 수준에 맞춰 채점해요`(이득)로

# 2026-09-03 오후 — stale 처리 재점검

**다음 세션(fable)이 이어받을 자리.** 아래 "남은 것"부터 읽으면 된다.

## 원칙 — 두 축을 섞지 않는다

| | 무엇 | 어떻게 |
|---|---|---|
| **지워지는 것** | 채점 결과 · 과제물 인식 결과 | 막지 않고, **저장할 때 모아서 한 번** 묻는다 |
| **낡는 것** | 문항–채점기준 연결 · 모범답안 | **표시만** 한다. 막지 않고, 저장 확인창도 못 잡는다 |

후자가 핵심이다. 저장 확인창은 *사라지는 것*만 잡으므로 **낡음은 화면에 신호를 남겨야 한다** — 줄리 우려(채점기준 바뀌면 ②연결도 다시 봐야 함)가 여기 걸린다.
공통 원칙은 [[feedback_optional_feature_minimal]] — 막지 않는다 / 상시로 알리지 않는다 / 저장할 때 한 번만 묻는다.

## 낡음 신호를 눈에 띄게

회색 배지 + `(다시 확인 필요)` 괄호로는 **고치고 나서 모르고 지나간다**(올립).

- **고도화 카드 행이 3상태** — `true` 초록 / `'redo'` 주황 / `false` 회색. 두 가지로 접으면 *"했는데 확인 필요"* 가 *"안 함"* 으로 읽힌다
- **카드 자체가 먼저 말한다** — `.adv-stale-on` 주황 테두리 + 연한 배경, 버튼 레이블도 `다시 확인하기`
- **`다시 확인` 칩 + 이유 한 줄** — 칩만 있으면 왜 다시 보라는지 모른다

## ②단 낡음 배너를 탭 바로 아래로

단 안에 두었더니 **세 번째 메시지라 묻혔다**(올립). 탭 바로 아래, **파란 "왜 하는지"보다 위**로 올리고 파란 배너와 같은 크기(16px/700)에 색만 주황.

**문구는 네 번 뒤집혔다.** 마지막 판정:

> **다시 연결하면 문항마다 바뀐 채점기준으로 채점해서 결과가 더 정확해져요.**
> 지금 연결은 채점기준을 고치기 전 상태예요. 이대로 채점해도 되고요. `AI가 다시 연결`

- `다시 연결해야 …` → `다시 연결하면 … 더 정확해져요` — **안 해도 새 채점기준으로 채점은 된다.** 막을 일이 아니면 막는 말투를 쓰지 않는다(26-09-03 올립)
- 직접 고치기와 재연결을 동등하게 뒀더니 *"그럼 채점기준 새로 만든 건 안 나오게 되잖아"* — **재연결 우선**으로

**동선**: ②단에 들어오면 팝업으로 **한 번만** 묻고(`S.staleAsked`), 닫아도 배너의 `AI가 다시 연결`로 언제든 다시 할 수 있다. `false → true` 전이일 때만 물음을 다시 연다 — 타이핑할 때마다 물으면 괴롭다.
