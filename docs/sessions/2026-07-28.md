## 논의로 정리된 것

- **Abel 제안(범용 LLM ↔ 도메인 특화 LLM 비유)** 수용하되 두 가지 조정 — "선생님이 채점하시던 방식 그대로"는 과약속이라 "선생님 기준에 더 가깝게"로, 간편 쪽은 실제 차이(채점기준 전체 적용)를 남김. LLM 비유는 내부 설명용으로만 두고 화면에는 노출하지 않음
- 설계 추가 3경로 중 **새로 만들기만 페이지**인 이유 — 간편/정교는 비교해 읽어야 하는 결정이라 페이지, 복사·자료실은 목록에서 하나 고르는 짧은 선택이라 모달

## 사고 기록

버튼 중앙정렬을 일괄 적용하며 쓴 정규식(`<button ... [\s\S]*? style="display:flex;`)이 **태그 경계를 넘어 카드 그리드 컨테이너까지 수정**해 목록 정렬과 문항 리스트 폭이 깨졌다. 백업본으로 복구 후 `[^>]` 기반 안전 패턴으로 재적용. → 원칙 11번 등록.
