# 2026-10-12 — 정교한 설계 PRD v2.1: 줄리 v2.0과 올립 v1.4 통합·간소화

노션 H-2608 페이지 맨 위에 v2.1 작성, v1.4는 올립이 `## 이전 문서` 토글로 이동. 상세 규칙은 [../precise-design.md](../precise-design.md).

### 한 것
- v1.4(올립) ↔ v2.0(줄리) 차이 정리 → 충돌 3건 결정(OCR 관계: 맥 10-07 확인 복원 / 기본 설계 수정 정책: 기개발이라 QA 참고 섹션으로 수록 / 띠·확인창: 디자인 소관).
- 간소화: 확인 9종→6종(C1~C6), `!` 해소 = 저장 1가지, ①②③ 저장본 정의, 1단계 저장 조건, C2 트리거, 진입점 2곳, n/4 서브텍스트 삭제, 2단계 경고 상시.
- 올립 지적으로 디자인 사양(크기·색·형태·위치·문구 전문·확인 UI 유형) 전부 제거 → §3 "화면별 동작"으로 개편. 원칙 #20 등록.
- 채점기준 AI 검토는 §7 백로그 1행.

### 줄리 리뷰(10-12 오후) 반영
- 댓글 7건: 인식 결과=학생 과제물? / 확인 필요 의미·해제 경로 구두 설명 요청 / 기본 설계 삭제 연쇄 한 줄 / 답안→모범답안 통일 / AI 실행 중 단계 이동 불가 / '미정'을 결정 또는 후속으로.
- 반영: §4.3 머리글 '학생 과제물 인식 결과', 미정 전부 제거(이번 배포 = 이미 나뉜 답안 그대로, 과제물 화면 안내 없음, 문항 순서 변경 미지원), 기본 설계 삭제 연쇄, AI 실행 중 이동·저장 불가, 모범답안 표기 통일(올립 직접).
- 줄리 댓글 패턴 → 원칙 #21(PRD 셀프 체크)로 등록.
- **채점요소 삭제 → 학생 `확인 필요` 조항 폐기.** v1.2(09-08 회의)부터 '지운 급간·채점요소로 매긴 점수만 삭제 → 그 학생 확인 필요'로 적혀 v1.4·v2.1까지 그대로 따라왔는데, 실제 정책(기개발)은 '태그는 교사가 입력할 게 생길 때만'. 삭제는 입력할 게 없으므로 태그 없음(총점만 변경). 09-10 빌 피드백(추가 시 채점완료→일부 채점)이 이 모델과 일치했는데 삭제 행은 고치지 않아 어긋남. 줄리 10-12 질문으로 드러나 올립이 구두 확인 후 §4.3·§5·QA 수정.

### 전체 검수(10-12 저녁)
- 올립 추가분(C7 AI 실행 중 닫기, 원칙 3개, 태그명 `선생님 확인 필요`)과 내 문장이 어긋난 곳 수정: §3.2 '닫아도 실행 계속' 삭제, 저장 버튼 '항상 활성'에 AI 실행 중 예외, 카드 라우팅에 `!` 예외(10-07 줄리 확정 누락분), 용어표에 '선생님 확인 필요' 추가, §6 '채점기준 수정'→'채점요소 삭제·추가', QA에 기본 설계 삭제 행. 줄리 스레드 2건에 정정 답글.

### 노션 편집 메모
- update_content는 토글·번호 목록 안의 줄을 잘 못 찾는다. 표 셀·불릿 단위의 짧은 old_str이 안전. 긴 블록 교체는 섹션 단위 old_str로 한 번에.
- 사용자가 동시에 편집 중이면 대조 문자열이 어긋난다 → 재조회 후 diff로 확인하고 다시 보낼 것.
