## 결론
평가 설계에 **시안 2개가 컨펌 대기**. 갈림길은 "AI가 제대로 채점할지를 무엇으로 판단하나".

| | 시안1 `evaluation_design_v5.html` | 시안2 `evaluation_design_v6.html` |
|---|---|---|
| 판단 근거 | 채점 전 **적합성 진단**(AI 판정) | **실제 채점 결과**(답안 1장 미리 채점) |
| 흐름 | 설계 → 진단 ① 채점기준 연결 ② 적합도 진단 | 설계 → 저장 팝업 → 미리보기 채점 → 다듬기 → 저장 전 시험 채점 → 확정 |
| 판정 표기 | `다시 볼 곳 있음` / `바로 채점 가능` | 판정 없음 — 점수를 직접 보여 줌 |

## 시안2 설계 사상
중간 판정·확인 단계를 없애고 **검증 지점을 "시험 채점 결과" 하나로** 모은다. 여기서 나머지가 따라 나온다.

- **고칠 수 있는 축이 둘**(채점기준 자체 / 문항 연결)인데도 순환이 안 생긴다 — 둘 다 한 번의 시험 채점으로 확인되므로. 다듬기 화면에 탭 2개로 나란히 두고, 기준을 바꾸면 AI가 연결을 그 자리에서 다시 만든다(저장 전이라 부담 없음)
- **확정 버튼에 확인 다이얼로그 없음** — 그 기준으로 채점한 결과를 보고 누르는 버튼이라 같은 확인을 두 번 받는 셈
- **확정·저장 후엔 설계 상세로** 보내 바뀐 기준을 눈으로 확인시킨다
- 연결 탭을 안 거치고 확정해도 AI가 자동 연결(끊긴 채로 저장하지 않음)

## 시안2 세부 확정
- **유도는 저장 직후 일회성 팝업.** 상시 배너는 폐기 — 미리보기는 저장된 설계로 도는데 저장 전 노출은 "수정 중인 내용으로 채점해 준다"로 읽힌다
- 미리보기 조건 = 평가명 + 채점기준 + **채점 가이드**(셋 다 있어야 돌아감). 이미 써 본 평가엔 다시 안 권함
- **AI 진단 의견은 한 덩어리 글** — 기준별 카드가 아니라, 연결이 문제면 연결을 보라 하고 기준이 문제면 고쳐 쓴 안을 제안
- `원래 기준 그대로 두기`도 화면을 빠져나감(들어온 곳으로). 다시 채점해 보여 줄 것이 없으므로
- 뒤로가기는 진입 경로를 따름 — 목록에서 왔으면 목록, 설계에서 왔으면 설계

## 잔재 정리
시안2에 시안1(진단) 코드가 남아 **선택 그룹 요약에 "진단 완료"가 뜨고 있었다.** 진단 전용 상태 6종(`dg`·`diagDone`·`diagResultKind`·`linksEdited`·`relinked`·`applied`), 없는 섹션에 표식 찍던 코드, 사라진 진단 결과를 경고하던 문구, 호출되지 않는 함수 2개 제거. `renderSavedBanner`→`renderSaveModal` 개명.
