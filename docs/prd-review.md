# PRD 리뷰어 시뮬레이션 — 줄리(디자인)·빌(개발) 관점 셀프 검토

PRD를 쓰거나 고칠 때 **보여 주기 전에** 이 파일로 자체 검토를 돌린다. 목표: 리뷰 댓글 0건.
"줄리 질문 올 것 같은 거 검토해줘" 요청도 이 파일 기준으로 수행한다.
결과는 "질문이 나올 문장 → 고친 문장" 표로 보고하고, 고칠 수 있는 건 묻지 않고 바로 고친다.

## 1. 줄리가 질문하는 패턴 (10-12 H-2608 PRD v2.1 댓글 11건 분석)

| 패턴 | 줄리가 실제로 물은 것 | 예방 규칙 |
|---|---|---|
| A. 용어가 어느 화면 객체인지 | "인식 결과가 학생 과제물 인식인가요?", 답안/모범답안 구분 | 용어표에 "어느 화면의 어떤 객체·기존 태그"를 적고, 기존 개념은 '기존 X와 동일'로 명시. 같은 대상은 한 단어만(문서 완성 후 grep) |
| B. 상태 전이 빈칸 | "AI 실행 중 닫으면 계속 도나요?", "삭제 후 다시 추가하면 매칭은?" | 객체 × 사건(생성·수정·삭제·상위 삭제·비동기 실행 중·실패·중단·초기화·재진입) 표를 머릿속으로 채워 빈칸이 없게. 특히 **실패·중단·재진입** 세 칸 |
| C. 한 대상에 두 규칙 | C4 셀 "모두 지우고 다시 연결" + "실패 시 유지" | 같은 행동이 두 곳 이상에 적히면 문장을 나란히 놓고 결과가 같은지 대조(§본문·확인 표·QA 표 3곳) |
| D. 미정·확인 필요 문구 | "미정(§3.3) 이거 왜 미정이죠?" | '미정·보류·확인 필요·개발 확인 필요'를 본문에 남기지 않는다. 이번 배포 동작 + 후속 배포 항목으로 쓴다 |
| E. 개발 가능 여부 | 유지·되돌리기 문장마다 "@빌 확인 부탁" | 백엔드 처리 순서에 걸리는 문장(실패 시 유지, 되돌리기, 삭제 연쇄, 비동기 중 조작)은 PRD에 넣기 전에 올립이 빌에게 예/아니오로 확인. 줄리에게는 "개발 확인은 올립이 한다"를 먼저 알린다 |
| F. 범위 질문 | "문항 바뀌면 OCR 다시 돌려야 하지 않나요?" | 첫 배포 범위를 §0에 한 줄로: 주 흐름 + 확인 C1~Cn까지만 화면 정의, 드문 경우는 기본 실패 안내·기본 확인창으로 통일. 비범위는 '누군가 할 뻔한 것'만 사유 한 줄로 |

줄리 특성 요약: 틀린 질문은 거의 없다. 1:1 대응이 안 되는 용어, 전이표 빈칸, 개발 미확인 문장을 정확히 짚는다. 10-07에 OCR 규칙이 뒤집힌 뒤로 개발 확인을 직접 챙기는 습관이 생겼다. 구두 설명·짧은 결정문을 선호한다.

## 2. 빌이 짚는 구현 사실 (PRD 문장에 영향)

- AI 실행은 비동기. DB에 기록되지 않은 건 실패도 화면에 못 보여 준다 → 실행 결과는 항상 기록, 데이터는 성공 시만 교체.
- 활동지 재업로드 = 기존 파일 삭제 후 업로드. 문항은 활동지에 딸린 데이터라 함께 삭제 → 되돌리기 없음.
- 활동지·문항과 OCR 결과(학생 답안)는 분리. 참고 데이터가 지워져도 OCR 결과는 남는다.
- 같은 활동지에 문항 추출은 여러 번 가능. AI 연결은 1회 실행 전제라 재실행은 추가 작업.
- "안 좋다·추가 작업 필요"는 동의가 아니다. 되묻는다.

## 3. 검토 절차 (PRD 초안 완성 직후, 보여 주기 전)

1. 용어표의 각 용어 옆에 화면 객체가 있는지 → 없으면 추가.
2. 다의어 grep: 답안/모범답안/학생 답안, 인식/문항 인식/과제물 인식, 확인 필요/선생님 확인 필요, 저장/저장본/초안.
3. 행동마다 실패·중단·재진입 세 칸이 적혀 있는지. 비동기 행동은 "닫기 → ?" 한 줄 필수.
4. 같은 행동이 본문·확인 표·QA 표에서 같은 결과인지 3곳 대조.
5. 본문에서 '미정·보류·확인 필요·개발 확인·갱신 필요·날짜·사람 이름' grep → 전부 제거(출처는 docs 결정 이력에).
6. 표 행을 참조하는 ID(C4, §3.3)는 이름 병기.
7. 백엔드에 걸리는 문장 목록을 뽑아 올립에게 "빌에게 확인할 것"으로 따로 보고(PRD에는 안 남김).
8. 범위 한 줄(§0)과 비범위가 있는지.

## 4. 보고 형식

- 표 1개: "질문이 나올 문장 | 어느 패턴(A~F) | 고친 문장". 고친 건 이미 반영된 상태로 보고.
- 그 아래 "빌 확인 필요 문장" 목록(예/아니오 질문 형태로 써서 올립이 그대로 붙여 넣게).
- 설명은 붙이지 않는다.
