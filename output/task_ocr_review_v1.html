문항 수정

수정한 문항은 이 평가의 모든 학생 과제물 인식 결과에 동일하게 적용됩니다. 학생별로 따로 수정할 필요가 없습니다.

수식 입력

자주 쓰는 기호를 누르거나 직접 입력하세요. 입력한 수식은 문항에 $수식$ 형태로 삽입됩니다.

과제물 인식을 시작합니다

업로드된 과제물의 필기 내용을 AI가 자동으로 인식합니다. 인식이 완료되면 AI 채점을 진행할 수 있습니다.

인식 정확도가 낮은 문항은 AI가 자동으로 감지합니다. 과제물 관리의 과제물 인식 결과 확인 버튼을 눌러 원본과 대조하여 확인·수정해 주세요.

원래 인식 결과로 되돌릴까요?

이 문항의 수정 내용이 사라지고, AI가 처음 인식한 결과로 돌아갑니다. (이 문항만 적용돼요)

과제물을 다시 인식할까요?

이 학생의 인식 결과에 수정한 내용이 있어요. 다시 인식하면 수정한 내용이 사라지고 AI가 새로 읽은 결과로 바뀝니다.
